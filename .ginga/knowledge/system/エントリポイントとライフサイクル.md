## エントリポイントとライフサイクル
エントリポイントは `JhipsterSampleApplicationApp#main`（`src/main/java/io/github/jhipster/sample/JhipsterSampleApplicationApp.java`）。`@PostConstruct` の `initApplication` で `dev` と `prod`・`cloud` の同時有効を検出し、`DefaultProfileUtil.addDefaultProfile` で既定プロファイル `dev` を設定する。WAR デプロイ用の入口として `ApplicationWebXml` もある。リクエストのライフサイクルは、CORS フィルタ → セキュリティフィルタチェイン（JWT 検証、パスごとの認可）→ メソッドセキュリティ（`@PreAuthorize`）→ リソースクラス（Bean Validation）→ サービスまたはリポジトリ → JSON 応答、であり、例外は `web/rest/errors/ExceptionTranslator.java` が RFC 7807 形式に変換する（`docs/999_標準化/主要処理フロー.md`、`docs/050_内部設計/01_共通仕様書/【JHipsterサンプルアプリ】アーキテクチャ設計書.md`）。
