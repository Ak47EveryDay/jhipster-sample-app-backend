## エントリポイントとライフサイクル
起動クラスは `JhipsterSampleApplicationApp`（src/main/java/io/github/jhipster/sample/JhipsterSampleApplicationApp.java）。`main` で `DefaultProfileUtil.addDefaultProfile` により既定プロファイル `dev` を設定し起動する。`@PostConstruct initApplication` で `dev` と `prod`（および `dev` と `cloud`）の同時有効を検出してエラーログを出す。WAR デプロイ用の入口として `ApplicationWebXml` もある。
1 リクエストのライフサイクル：CORS フィルタ → SecurityFilterChain（JWT 検証・パスごと認可・`@PreAuthorize`）→ REST リソースクラス（Bean Validation、`LOG.debug("REST request to ...")`）→ サービスまたはリポジトリ → Hibernate（H2/PostgreSQL）→ JSON 応答。REST 層の例外は `web/rest/errors/ExceptionTranslator.java` が RFC 7807 形式に変換する（docs/999_標準化/主要処理フロー.md、docs/03_詳細設計/01_共通仕様書/【JHipsterサンプルアプリ】アーキテクチャ設計書.md）。
起動時に `LiquibaseConfiguration` が `classpath:config/liquibase/master.xml` を適用しスキーマと初期データを用意する（src/main/java/io/github/jhipster/sample/config/LiquibaseConfiguration.java）。
