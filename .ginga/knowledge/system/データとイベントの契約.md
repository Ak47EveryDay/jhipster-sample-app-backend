## データとイベントの契約
REST の入出力は DTO（`service.dto`：`AdminUserDTO`、`UserDTO`、`PasswordChangeDTO`）、VM（`web.rest.vm`：`LoginVM`、`ManagedUserVM`、`KeyAndPasswordVM`）、またはエンティティ（`BankAccount`、`Operation`、`Label`、`Authority`）のいずれかで受け渡す。JSON のキーはキャメルケース。ただし JWT 発行の応答は `id_token` にリネーム出力し、`User` の `password`・`activationKey`・`resetKey`・`authorities` は `@JsonIgnore` で除外、監査項目は `allowGetters = true`、関連の循環参照は `@JsonIgnoreProperties` で防止する（`docs/050_内部設計/01_共通仕様書/【JHipsterサンプルアプリ】DTOマッピング設計書.md`）。認証は JWT（HS512）で、クレームは `sub`（ログインID）、`auth`（権限名を半角空白連結、`authority-prefix: ''`・`authorities-claim-name: auth` で読む）、`userId`、`iat`、`exp`。ログイン要求は `username`・`password`、応答は `id_token`（`docs/050_内部設計/01_共通仕様書/【JHipsterサンプルアプリ】セキュリティ設計書.md`）。エラー応答は RFC 7807 の JSON で、`type`（URI の末尾要素を略称として使用）、`title`、`status`、`detail`、`message`（メッセージキー `error.*`）、`path`、条件付きで `fieldErrors`（`objectName`・`field`・`message` の配列）と `params` を持つ。成功時のアラートはヘッダ `X-jhipsterSampleApplicationApp-alert`／`-params`／`-error` で返す（`docs/050_内部設計/01_共通仕様書/【JHipsterサンプルアプリ】例外処理設計書.md`、`docs/050_内部設計/01_共通仕様書/【JHipsterサンプルアプリ】メッセージ.md`）。
