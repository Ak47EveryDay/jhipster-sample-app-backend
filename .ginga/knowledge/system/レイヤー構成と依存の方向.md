## レイヤー構成と依存の方向
本体ソースは `src/main/java/io/github/jhipster/sample/` 配下にパッケージ分割される：`config`（Spring 設定）、`domain`（JPA エンティティ）、`repository`（Spring Data JPA）、`service`／`service.dto`／`service.mapper`（業務処理と DTO）、`security`（認証補助）、`web.rest`／`web.rest.errors`／`web.rest.vm`（REST 層）、`aop.logging`（ログ AOP）、`management`（メトリクス）（docs/999_標準化/レイヤー別開発ガイド.md）。
依存方向は ArchUnit の階層ルールで制約される：`config` はどのレイヤからも参照されず、`web` は Config のみから、`service` は Web・Config から、`security` は Config・Service・Web から、`repository` は Service・Security・Web・Config から、`domain` は全レイヤから参照できる。`config.Constants` と `config.ApplicationProperties` への参照と起動クラスからの依存は対象外（docs/999_標準化/レイヤー別開発ガイド.md、docs/03_詳細設計/01_共通仕様書/【JHipsterサンプルアプリ】アーキテクチャ設計書.md）。
ユーザ関連は リソースクラス → サービス → リポジトリ の 3 段だが、口座・取引・ラベル・権限はリソースクラスがリポジトリを直接呼ぶ（docs/999_標準化/システム知識整理.md）。
