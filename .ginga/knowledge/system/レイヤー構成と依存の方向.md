## レイヤー構成と依存の方向
ルートパッケージ `io.github.jhipster.sample` 配下に、`config`（設定クラス）、`domain`（エンティティ）、`repository`（Spring Data JPA）、`service`（業務処理・`service.dto`・`service.mapper`）、`security`（認証補助）、`web.rest`（REST コントローラ・`web.rest.errors`・`web.rest.vm`）、`aop.logging`、`management` を置く（`docs/999_標準化/レイヤー別開発ガイド.md`）。依存方向は ArchUnit のテスト `TechnicalStructureTest`（`src/test/java/io/github/jhipster/sample/TechnicalStructureTest.java`）が検証し、「Config はどのレイヤーからも参照不可、Web は Config のみから、Service は Web・Config から、Security は Config・Service・Web から、Persistence は Service・Security・Web・Config から、Domain は Persistence・Service・Security・Web・Config から参照され得る」規則である。`config.Constants` と `config.ApplicationProperties` への依存と、起動クラスからの依存は対象外（`docs/999_標準化/レイヤー別開発ガイド.md`）。口座・ラベル・取引の REST コントローラはサービスを挟まずリポジトリを直接呼ぶ。
