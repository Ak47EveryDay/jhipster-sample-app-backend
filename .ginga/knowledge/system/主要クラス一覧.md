## 主要クラス一覧
| クラス | ファイルパス | 責務 | 主な公開メソッド |
|---|---|---|---|
| `JhipsterSampleApplicationApp` | src/main/java/io/github/jhipster/sample/JhipsterSampleApplicationApp.java | 起動、既定プロファイル設定、起動ログ | `main`、`initApplication` |
| `AuthenticateController` | src/main/java/io/github/jhipster/sample/web/rest/AuthenticateController.java | ログインと JWT 発行 | `authorize(LoginVM)`、`isAuthenticated(Principal)`、`createToken` |
| `AccountResource` | src/main/java/io/github/jhipster/sample/web/rest/AccountResource.java | ユーザ登録・有効化・パスワード変更・リセット | `registerAccount`、`activateAccount`、`getAccount`、`saveAccount`、`changePassword`、`requestPasswordReset`、`finishPasswordReset` |
| `UserResource` | src/main/java/io/github/jhipster/sample/web/rest/UserResource.java | 管理者向けユーザ管理（/api/admin） | `createUser`、`updateUser`、`getAllUsers`、`getUser`、`deleteUser` |
| `PublicUserResource` | src/main/java/io/github/jhipster/sample/web/rest/PublicUserResource.java | 公開ユーザ一覧 | `getAllPublicUsers` |
| `AuthorityResource` | src/main/java/io/github/jhipster/sample/web/rest/AuthorityResource.java | 権限の CRUD | `createAuthority`、`getAllAuthorities`、`getAuthority`、`deleteAuthority` |
| `BankAccountResource` | src/main/java/io/github/jhipster/sample/web/rest/BankAccountResource.java | 口座の CRUD | `createBankAccount`、`updateBankAccount`、`partialUpdateBankAccount`、`getAllBankAccounts`、`getBankAccount`、`deleteBankAccount` |
| `OperationResource` | src/main/java/io/github/jhipster/sample/web/rest/OperationResource.java | 取引の CRUD | `createOperation`、`updateOperation`、`partialUpdateOperation`、`getAllOperations`、`getOperation`、`deleteOperation` |
| `LabelResource` | src/main/java/io/github/jhipster/sample/web/rest/LabelResource.java | ラベルの CRUD | `createLabel`、`updateLabel`、`partialUpdateLabel`、`getAllLabels`、`getLabel`、`deleteLabel` |
| `UserService` | src/main/java/io/github/jhipster/sample/service/UserService.java | ユーザ管理・有効化・パスワード・キャッシュ削除・定期削除 | `activateRegistration`、`completePasswordReset`、`registerUser`、`createUser`、`updateUser`、`deleteUser`、`changePassword`、`removeNotActivatedUsers` |
| `MailService` | src/main/java/io/github/jhipster/sample/service/MailService.java | メール送信（非同期・Thymeleaf） | `sendEmail`、`sendActivationEmail`、`sendCreationEmail`、`sendPasswordResetMail` |
| `UserMapper` | src/main/java/io/github/jhipster/sample/service/mapper/UserMapper.java | User と DTO の手書き変換 | `userToUserDTO`、`userToAdminUserDTO`、`userDTOToUser` 等 |
| `SecurityUtils` | src/main/java/io/github/jhipster/sample/security/SecurityUtils.java | 現在ユーザ/JWT の静的ユーティリティ | `getCurrentUserLogin`、`getCurrentUserJWT`、`getCurrentUserId`、`isAuthenticated` 等 |
| `DomainUserDetailsService` | src/main/java/io/github/jhipster/sample/security/DomainUserDetailsService.java | DB ユーザによる認証 | `loadUserByUsername` |
| `SecurityConfiguration` | src/main/java/io/github/jhipster/sample/config/SecurityConfiguration.java | フィルタチェイン・PasswordEncoder | `filterChain(HttpSecurity)`、`passwordEncoder` |
| `SecurityJwtConfiguration` | src/main/java/io/github/jhipster/sample/config/SecurityJwtConfiguration.java | JwtDecoder/JwtEncoder | `jwtDecoder`、`jwtEncoder` |
| `SecurityMetersService` | src/main/java/io/github/jhipster/sample/management/SecurityMetersService.java | JWT 検証エラーのカウンタ | `trackTokenInvalidSignature`、`trackTokenExpired`、`trackTokenMalformed` 等 |
| `ExceptionTranslator` | src/main/java/io/github/jhipster/sample/web/rest/errors/ExceptionTranslator.java | 例外を RFC 7807 に変換 | `handleAnyException` |
