## 拡張ポイント
Spring プロファイル（`dev`・`prod`・`tls`・`no-liquibase`・`api-docs`・`secret-samples` とテスト用 `testdev`・`testprod`）による動作分岐は `src/main/resources/config/application.yml` の `spring.profiles.group` と `pom.xml` の Maven プロファイルで定義する。アプリ固有の設定は `ApplicationProperties`（`src/main/java/io/github/jhipster/sample/config/ApplicationProperties.java`）に型付きフィールドを追加し、YAML の `application:` 配下に書く（`ignoreUnknownFields = false` のため未知のキーはエラー）。Liquibase のチェンジログ追加は `src/main/resources/config/liquibase/changelog/` に置き `master.xml` で `<include>` する。`application.yml` や `CacheConfiguration` などには JHipster 再生成用の `jhipster-needle-...` コメントが残るが、本リポジトリは再生成不可のため手動で保守する（`docs/999_標準化/設定とビルド手順.md`、`docs/999_標準化/REST・エンティティ追加手順.md`、`docs/999_標準化/ネーミング・コーディング規約.md`）。
