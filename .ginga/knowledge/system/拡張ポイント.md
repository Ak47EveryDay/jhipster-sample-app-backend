## 拡張ポイント
- Spring プロファイル駆動の分岐：`dev`／`prod`／`tls`／`secret-samples`／`api-docs`／`no-liquibase`／`test*`。プロファイルグループは `src/main/resources/config/application.yml` の `spring.profiles.group` で定義する（docs/03_詳細設計/01_共通仕様書/【JHipsterサンプルアプリ】アプリケーション設定情報.md）。
- アプリ固有設定は `src/main/java/io/github/jhipster/sample/config/ApplicationProperties.java`（`@ConfigurationProperties(prefix = "application")`）にフィールドを追加し、YAML の `application:` 配下に書く（docs/999_標準化/モジュール構成と共通部品.md）。
- 新エンティティ／REST エンドポイントの追加手順と Liquibase チェンジログの追加手順は docs/999_標準化/REST・エンティティ追加手順.md に定められている。チェンジログは `src/main/resources/config/liquibase/changelog/` に `<yyyyMMddHHmmss>_added_entity_<エンティティ>.xml` 形式で追加し、`master.xml` に include する（docs/999_標準化/モジュール構成と共通部品.md）。
- 未認許可パスの追加は `SecurityConfiguration#filterChain` の `requestMatchers(...)` に追加する（docs/999_標準化/モジュール構成と共通部品.md）。
- キャッシュ名は `config/CacheConfiguration` の `cacheManagerCustomizer` に登録し、`// jhipster-needle-ehcache-add-entry` の位置に追加する（src/main/java/io/github/jhipster/sample/config/CacheConfiguration.java）。
